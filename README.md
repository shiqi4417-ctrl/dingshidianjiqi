# 定时点击器（dingshidianjiqi）

一个用于 Android 的定时自动连点工具。通过在屏幕上悬浮一个常驻面板，你可以按设定的时间点，自动执行一组点击序列。

- **常驻悬浮面板**：不看主界面也能看到实时时钟、运行状态，可拖动，双击返回 App 主界面。
- **多时间点自动触发**：支持每天固定时刻、每小时某分某秒等多种触发模式，每个时间点可单独启用。
- **悬浮窗取点**：在时间点卡片里进入取点模式，点击屏幕任意位置即可把坐标加入该时间点的点击序列。
- **按北京时间调度**：内置 SNTP 网络校时，调度命中判定基于北京时间，不依赖设备时区。

UI 用 Flutter 编写；悬浮窗、无障碍点击注入、定时调度、配置持久化等核心能力由 Android 原生（Kotlin）实现。

## 功能一览

- **多时间点**：添加多个时间点，每个时间点可单独启用 / 停用、删除、排序、修改；开启某个时间点开关前会先校验无障碍权限，未开启则拒绝并提示跳转设置。
- **触发模式**：`每天 时:分:秒` 或 `每小时 分:秒`；一个时间点可选择多个时 / 分 / 秒组合。
- **重复次数与间隔**：每个时间点可设置总触发次数与相邻两次的间隔毫秒数。
- **多步点击序列**：每个时间点包含一组步骤，每步 = 屏幕坐标 + 到下一步的延时。
- **分组管理**：可新建 / 重命名 / 删除分组，时间点必须归属于某个分组；分组名全局唯一，新建 / 重命名重名时会被拒绝；删除时间点后若其所在分组变空（默认分组除外）会自动删除该空分组。
- **悬浮窗取点**：在时间点卡片内进入取点模式，点击屏幕目标位置即可把坐标加入该时间点的点击序列（取点建议先用系统缩放对齐屏幕分辨率，坐标按当前屏幕换算）。
- **常驻悬浮面板**：面板显示实时时钟、当前状态，可拖动移动位置，双击返回 App 主界面。
- **按北京时间调度**：SNTP 对时，命中判定与「下一次触发时刻」均按北京时间计算。
- **日志**：底部实时日志记录每次触发的计划时刻 / 实际时刻与偏差。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 显示在其他应用上层（悬浮窗） | 显示常驻悬浮面板并取点 |
| 无障碍服务 | 通过系统手势 API 注入点击，实现自动连点 |
| 通知 | 前台服务常驻通知，保证后台存活 |
| 网络（INTERNET） | 仅用于 SNTP 校时（北京时间） |

> 无障碍与悬浮窗都是高敏感能力，工具只在你主动添加的时间点到达时执行点击，不会在后台自行采集或外传任何数据。

## 快速开始

1. 安装 APK（见下方「构建」），Android 会提示未知来源，允许后安装。
2. 打开应用，按提示依次授权：
   - **悬浮窗**：允许「显示在其他应用上层」。
   - **无障碍**：在系统「无障碍」里找到本应用并开启（关闭时点击注入不会生效；未开启时尝试开启某个时间点会先被拒绝并跳转设置）。
3. 点右下角**新增时间点**：设置时 / 分 / 秒与触发模式，选择要加入的**分组**，保存。
4. 在对应**时间点卡片**上进入取点模式，点击屏幕目标位置即可把坐标加入该时间点的点击序列。
5. 用「立即执行一次」验证点击序列是否生效。
6. 到点后按设定的时间自动执行，日志与悬浮面板会显示运行状态。

### 悬浮面板操作

- **拖动**：按住面板移动位置。
- **双击**：返回 App 主界面。

## 构建

环境要求：JDK 17、Android SDK、Flutter（含 Dart）。

仓库中已提供一键构建脚本（会设置环境变量、跑单测、打 release 包）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build-apk.ps1
```

或直接用 Flutter 命令：

```bash
flutter build apk --release
```

产物：`build/app/outputs/flutter-apk/app-release.apk`。

### 网络提示

国内环境构建时部分 Google 依赖可能无法直连，请在 `android/gradle.properties` 里按需配置代理或镜像源（本项目中默认已指向阿里云镜像）。

## 技术栈与目录结构

- **前端 UI**：Flutter / Dart
- **原生能力**：Android Kotlin（悬浮窗 `WindowManager`、无障碍 `AccessibilityService`、调度线程、SNTP）
- **配置持久化**：SharedPreferences

```
lib/          Flutter 界面与模型
android/      Android 原生模块（悬浮窗 / 无障碍 / 调度 / 数据）
test/         Flutter 测试
android/app/src/test/   Kotlin 单元测试
```
